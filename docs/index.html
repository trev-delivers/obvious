Design system v0.1.0 trev-delivers/obvious

obvious

Six apps, four different stacks. They can’t share a component library: one’s a static site, one keeps its styles in a template string, two are Next on Tailwind, one’s a script that draws an SVG. So they share tokens instead. Spacing, type, motion and focus are the same everywhere. Colour, typeface, --ds-radius-base and --ds-density are what each app gets to change.

This theme

Everything below is painted in whichever theme you pick. These four dials are all an app can change.

Colour

31 semantic tokens

Every theme sets the same 31. The build won’t emit if one is missing, so a theme can’t drop a token and quietly inherit the last one’s value.

Using it

The tokens get copied into each app rather than installed. Four of the repos are private and two don’t build with npm at all, so a dependency would mean deploy keys everywhere for a few KB of CSS. Each app has the sync script and a generated ds/ folder; ds/.version does the job of a lockfile.

node scripts/sync-ds.mjs             # pull main into ds/
node scripts/sync-ds.mjs --ref v0.2.0  # pin a tag
node scripts/sync-ds.mjs --check     # CI: fail if ds/ is stale
