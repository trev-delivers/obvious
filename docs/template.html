obvious

Six apps on four different stacks. What they share is not a component library, because no component library spans a static site, a Vite app that styles itself from a template string, two Tailwind v4 Next apps and a README card generator. What they share is a set of invariants and four dials. Spacing, type scale, motion curves and focus geometry are identical everywhere. Palette, typeface, --ds-radius-base and --ds-density are what an app is allowed to differ on.

The voice

Everything below this line is painted in the selected theme. The four dials are the only things it is allowed to change.

Space and radius

One dial moves the set

Spacing never changes between apps. Radius always does: every step derives from --ds-radius-base, so switching theme moves the whole set at once and the ratio between a small and a large corner stays put. Watch the squares as you change theme.

Using it

Tokens are vendored rather than installed. Four consumers are private repos and two are not npm-built at all, so a dependency would mean deploy-key auth in every build for the sake of a few KB of CSS. Each app carries a copy of the sync script and a generated ds/ folder instead, with ds/.version standing in for a lockfile.

node scripts/sync-ds.mjs             # pull main into ds/
node scripts/sync-ds.mjs --ref v0.2.0  # pin a tag
node scripts/sync-ds.mjs --check     # CI: fail if ds/ is stale
